Step 1 安装脚本管理器

脚本运行在「篡改猴」之上，请先安装：

Tampermonkey 官网

Step 2 开启开发者模式（重要）

Edge / Chrome 会拦截第三方扩展，需要手动开启开发者模式后刷新页面。
  • 地址栏输入 chrome://extensions/ 或 edge://extensions/
  • 打开右上角「开发者模式」开关并重新刷新本页

Step 3 安装脚本

游戏内快捷键

按键功能说明
M呼出 / 关闭菜单（录屏模式下需长按 2 秒）
A / B大厅自动加入 A 队 / B 队
H自动加入任意有空位的队伍
X紧急停止所有自动线程
T一键闪退，返回大厅
F10屏幕截图（剪贴板 / 下载）
F5手动刷新游戏页面
特色提示：录屏模式会隐藏全部脚本 UI 与个人信息；防封挂机会模拟随机按键；管理员模式仅在本地生效。
